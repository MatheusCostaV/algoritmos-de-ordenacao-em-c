# Profiling com gprof

- Entrada, tamanho e ambiente: [preencher]
- Comando executado: `make profile`
- Referência: `docs/perfil_bruto.txt`

Use a seção Flat Profile para registrar as funções com maior tempo próprio e quantidade de chamadas. Use o Call Graph para explicar de onde vieram as chamadas. Comente se o tempo observado é coerente com os algoritmos e a entrada usada.
